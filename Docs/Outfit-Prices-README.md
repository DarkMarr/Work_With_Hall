## วิธีใช้

แก้ตารางฝั่งไหนก็ได้แล้วบอก multivac ให้ sync อีกฝั่ง จากนั้นรันเมนู
`QuizGame/Setup/Create Outfit Shop Products`

ตัวอ่าน csv ยังข้ามบรรทัดที่ขึ้นต้นด้วย `#` เหมือนเดิม เผื่อมีใครอยากแปะหมายเหตุกลับเข้าไป
ไฟล์จึงยังใช้แทนกันได้ทั้งแบบมีและไม่มีคำอธิบาย

## คอลัมน์ Source

| ค่า | ความหมาย |
| --- | --- |
| `Shop` | วางขายในร้าน ต้องมีราคามากกว่า 0 อย่างน้อยหนึ่งสกุล |
| `Craft` | ได้จากการคราฟต์ ไม่วางขาย |
| `Drop` | ได้จาก Lucky Draw ไม่วางขาย |

ย้ายชุดเป็น `Craft` หรือ `Drop` แล้วของจะหายจากร้านทันทีที่รันเมนู

ค่าทั้งหมดดึงมาจาก NOTE ในเอกสาร item (15_KKnDD แท็บ OUTFIT) ที่ระบุ
`S.GOLD` / `S.GEM` / `CRAFT` / `DROP` ไม่ได้เดา ถ้าเอกสารเปลี่ยนก็แก้คอลัมน์นี้ตามได้เลย

## คอลัมน์ Coin / Gem

ราคาต่อ **1 ชิ้น** ไม่ใช่ทั้งชุด ชุดหนึ่งมี 4 ชิ้น Head Body Hand Back
ใส่ `0` = ไม่ขายในสกุลนั้น

## ที่มาของตัวเลข

ตัวเลขที่กรอกไว้เป็นค่าตั้งต้นที่ฝั่ง dev เสนอ **ยังไม่ผ่าน Game Designer**
เอกสาร item นิยาม `coin_cost` กับ `gem_cost` ไว้แล้ว แต่ยังไม่มีค่าจริงสักชิ้น

ยึดจากรายได้จริง ทองเฉลี่ยวันละ 3200 (DOC 02 แท็บ etc) single ~1200 multi ~1600
และคุมให้อยู่ในช่วงที่เกมตั้งราคาไว้แล้ว coin 100-4000 gem 30-700

| Rarity | ราคาที่เสนอ | เหตุผล |
| --- | --- | --- |
| Common | 800 coin x 4 = 3200 | ชุดเต็มเท่าทองหนึ่งวันพอดี |
| Uncommon | 1600 coin หรือ 120 gem | ยังไม่มีชุดไหนใช้ ทั้ง 12 ชุดเป็นของดรอป |
| Rare | 250 gem | เท่ากับ CarryOn3_Gem ที่มีอยู่แล้ว |
| SuperRare | 500 gem x 4 = 2000 | แพงสุดในร้าน ยังต่ำกว่าเพดาน gem เดิมที่ 700 ต่อชิ้น |
