## รูปแบบไฟล์ที่ต้องส่งมา

ทำเป็น PSB หนึ่งไฟล์ต่อหนึ่งชุด วางใน `Assets/Art/Sprites/Fashion/` ตั้งชื่อ
`Fashion_<Rarity>_<SetName>.psb` เช่น `Fashion_UC_Party.psb`, `Fashion_R_Noble.psb`

**กติกาเดียวกับของเดิมทุกข้อ** (ดู `Docs/Character-PSB-Export-Spec.md`):

- document 600×600 และ **ทุกเลเยอร์ต้องกินเต็มผืน** ไม่งั้น PSD Importer จะ crop ให้
  ใส่ fill เต็มผืน alpha 1/255 กันไว้
- ชื่อเลเยอร์ใช้ชุดเดิม: `hat` `lower` `L_arm` `R_arm` `prop` `back`
  - `hat` → ช่อง Head
  - `lower` + `L_arm` + `R_arm` → ช่อง Body (แขนเสื้อนับเป็นชิ้นเดียวกับตัวเสื้อ)
  - `prop` → ช่อง Hand
  - `back` → ช่อง Back
- ให้เห็นเฉพาะ group ของชุดนั้น group เดียว เพราะ importer ส่ง sprite เฉพาะเลเยอร์ที่เปิดอยู่

พอไฟล์เข้ามาแล้ว รันสองเมนูนี้ตามลำดับ ระบบจะสร้าง asset ให้เอง:

1. `QuizGame/Setup/Create Fashion Set SO Assets (from Fashion PSBs)`
2. `QuizGame/Setup/Create Fashion Reward Items + Fill Destination Pools`
