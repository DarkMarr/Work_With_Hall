Key ตั้งตามกฎในชีต Localization แท็บ Rule คือใช้จุดแยกหมวด:
`item.outfit.<ชุด>.<ช่อง>.name` และ `.description` เช่น `item.outfit.c_baseball.back.name`
ชื่อชุดคือ id ในโปรเจ็กต์ตัดคำว่า `Fashion_` ออก จึงมี rarity ติดมาด้วย
เพื่อไม่ให้ชุดเมืองระดับ UC กับ R ชนกัน

## ข้อควรระวัง ถ้าจะ pull localization

`Assets/Settings/Localization/Tables/GameItem/Item.asset` ตั้ง **`m_RemoveMissingPulledKeys: 1`**
แปลว่าเวลา pull จากชีต Localization ระบบจะ **ลบ key ที่ไม่มีในชีตทิ้ง**

ตอนนี้ key 112 ตัวนี้อยู่ในโปรเจ็กต์อย่างเดียว ยังไม่ได้อยู่ในชีต
**ถ้า pull ก่อนเอาแถวไปแปะ ข้อความจะหายทั้งหมด**

วิธีแก้คือเอาคอลัมน์ Key / en / ja / th จาก `Docs/Outfit-Text.csv`
ไปแปะต่อท้ายแท็บ **Item** ในชีต Localization
(`1686qsR-AxEDsmrbS4ce3OYNwNtLX5CP9Uu-lAL7clV4`) ซึ่งคอลัมน์เรียง A=Key B=en C=ja D=th พอดี

## กฎที่ตัว import ใช้

**ข้อความของชิ้นไหนจะถูกใช้ ก็ต่อเมื่อชิ้นนั้นมีชื่อ**

ไม่ใช่กฎที่ตั้งเล่น ๆ — ในชีตมี 7 แถวที่ช่องชื่อว่าง แต่ช่องคำอธิบายถูกใช้จดโน้ตสั่งงาน Art ไว้
ถ้าเอามาใช้ตรง ๆ ผู้เล่นจะเห็นโน้ตพวกนี้เป็นคำอธิบายไอเทมในร้าน

| ชิ้น | ข้อความในช่องคำอธิบาย |
| --- | --- |
| `Fashion_C_CloudVibe__HeadDecoration` | น่าจะมีแล้วแต่ไม่แน่ใจ ถ้ายังไม่มีเอาแว่นกันแดดคาดหัวก็ได้ |
| `Fashion_C_LeisureDays__HeadDecoration` | น่าจะมีแล้วแต่ไม่แน่ใจ ถ้ายังไม่มีใส่แว่นอะไรซักอย่าง |
| `Fashion_C_Summer__HeadDecoration` | น่าจะมีแล้วแต่ไม่แน่ใจ เอาหมวกซักใบมาเปลี่ยนสีก็พอ |
| `Fashion_R_Bangkok__HeadDecoration` | ยังนึกไม่ออกเลยแฮะ |
| `Fashion_R_London__BackDecoration` | ยังนึกไม่ออก |
| `Fashion_R_NewYork__HeadDecoration` | ใส่หมวกน่าจะยากหาอะไรวางบนหัวหน่อยละกัน |
| `Fashion_UC_Cairo__BodyDecoration` | เสื้อลายดวงตา horus ก็ได้ |

โน้ตพวกนี้ยังอยู่ในชีตเหมือนเดิม ไม่ได้ไปลบของใคร แค่ไม่ถูกดึงเข้าเกม
พอ GD เติมชื่อให้ชิ้นไหน รันเมนูใหม่รอบเดียวข้อความของชิ้นนั้นก็เข้าทันที

ชิ้นที่ไม่ถูกผูกจะใช้ชื่อสำรองที่ `EquipmentItemSO` สร้างจาก id เช่น "Summer Head Decoration"
ซึ่งอ่านรู้เรื่องกว่าช่องว่าง

เมนูนี้รันซ้ำได้ ถ้าชีตเปลี่ยนแล้วข้อความถูกถอดออก การรันรอบใหม่จะลบ key
กับ binding ที่ไม่ควรมีออกให้ด้วย ไม่ใช่เพิ่มอย่างเดียว

## ที่อยากให้ Game Designer ช่วยดู

1. **Cairo ฟาโรห์ ดูสลับช่อง** — แถว `Type=Hand` เขียนว่า "ชุดฟาโรห์" ซึ่งเป็นชุด น่าจะเป็น Body
   ส่วนแถว `Type=Body` เขียนว่า "ไม้เท้าฟาโรห์" ซึ่งเป็นไม้เท้า น่าจะเป็น Hand
   ไม่ได้แก้ให้เองเพราะเป็นการตัดสินใจเรื่องเนื้อหา
2. **มี 7 แถวที่ใช้ช่องคำอธิบายจดโน้ตสั่งงาน Art** (ตารางด้านบน) อยากให้ย้ายโน้ตไปคอลัมน์ NOTE
   แล้วเขียนคำอธิบายจริงลงช่องนั้นแทน จะได้ไม่ต้องพึ่งกฎ "ไม่มีชื่อ = ไม่ดึง" 
3. **ชุดรายเมือง 12 ชุด** ยังไม่มี EN/JP และคำอธิบาย
